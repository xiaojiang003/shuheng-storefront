## 一、站点定位与导航设计原则

Shuheng 是一个 **B2B 帽类定制 / 批发询盘独立站**，不是传统零售电商。

| 原则 | 说明 |
|------|------|
| 转化目标 | 引导买家发起 **Quick Quote**、填写 **Contact 表单** 或通过 **WhatsApp** 联系，而非购物车结账 |
| 信任建立 | 通过 Cases、About、Blog、FAQ 等内容降低 B2B 采购决策门槛 |
| 产品教育 | 通过 Collection、廓形页、尺码指南帮助买家选对帽型与规格 |
| 全站触达 | Header / Footer / FAB / 首页各区块均可触发询盘，参考 NOVAE、Fuanger 竞品策略 |

## 三、各导航页详细功能

### 3.1 HOME — 首页 `/`

**页面文件：** [`src/pages/HomePage.tsx`](../src/pages/HomePage.tsx)

**业务目标：** 作为站点总入口，在 30 秒内让 B2B 买家了解「你是谁、能做什么、如何开始询盘」。

#### 页面区块（自上而下）

| # | 区块 | 组件 | 功能说明 |
|---|------|------|----------|
| 1 | Announcement Bar | `AnnouncementBar` | 顶部轮播 MOQ / 打样 / 季节款，可关闭 |
| 2 | Header | `Header` | 首页透明变体，覆盖 Hero 背景 |
| 3 | Hero | `HeroSection` | 生活方式主图 + MOQ/Factory/Response 三 badge + Quick Quote CTA |
| 4 | Category Grid | `CategoryGrid` | 4 格分类入口（6-Panel / Trucker / Bucket / Dad Hats） |
| 5 | Factory Stats | `FactoryStats` | 成立年份、MOQ、出口市场数、语言支持数 |
| 6 | New Arrivals | `NewArrivalsRail` | 新品产品卡（API 驱动，失败时用静态兜底） |
| 7 | Silhouette Slider | `SilhouetteSlider` | 8 种廓形横向滑轨，链至 `/silhouette/:key` |
| 8 | Capability Icons | `CapabilityIcons` | 4 张工厂能力卡片 |
| 9 | Production Process | `ProductionProcess` | 5 步生产流程 + 工厂产线图 |
| 10 | Material Strip | `MaterialStrip` | 5 种材质图标与简述 |
| 11 | Certification Badges | `CertificationBadges` | 认证与 QC 背书行 |
| 12 | Testimonials | `Testimonials` | 客户评价轮播 |
| 13 | Size Education | — | 跳转 `/sizing-guide` 与 `/fit-finder` |
| 14 | FAQ Preview | `FaqPreview` | 3 条 FAQ 预览 + 链接 `/faq` |
| 15 | Enquiry Block | `EnquiryBlock` | Quick Quote + WhatsApp 直链 |
| 16 | Footer | `Footer` | 全站页脚 |

#### 可跳转的子页面（非 Header 导航项）

- `/sizing-guide` — 完整 US/IN/CM 尺码映射表
- `/fit-finder` — 五步廓形推荐测验
- `/faq` — 完整 FAQ 页
- `/silhouette/:key` — 8 廓形独立教育页
- `/collection/:category` — 从 Category Grid 进入分类列表

#### SEO

输出 Organization JSON-LD（`buildOrganizationJsonLd`）。

### 3.2 COLLECTION — 产品集合 `/collection`

**页面文件：** [`src/pages/CollectionPage.tsx`](../src/pages/CollectionPage.tsx)  
**数据来源：** [`src/data/products.mock.ts`](../src/data/products.mock.ts)（当前 4 个 mock SKU）

**业务目标：** 让买家浏览帽款目录，进入详情页了解规格后发起询盘。

#### 路由变体

| 路由 | 说明 | 示例 |
|------|------|------|
| `/collection` | 全部商品 | 显示 4 个 SKU |
| `/collection/:category` | 按分类过滤 | `/collection/trucker-hats` |
| `/collection?silhouette=:key` | 按廓形过滤 | 从 Silhouette Slider 跳入 |
| `/collection?sort=newest` | 按新品排序 | mock 数据倒序 |

#### 页面功能

| 功能 | 说明 |
|------|------|
| 商品网格 | `ProductGrid` 展示 ProductCard（图 / 标题 / 价格区间 / MOQ / 材质图标） |
| 结果计数 | 显示 `{n} results` |
| 点击产品卡 | 跳转 PDP `/product/:slug` |

#### 关联子页面：商品详情 PDP `/product/:slug`

**页面文件：** [`src/pages/ProductPage.tsx`](../src/pages/ProductPage.tsx)

| 功能 | 说明 |
|------|------|
| 面包屑 | Home → 分类 → 商品名 |
| 6 角度 Gallery | 3QL / F / R / LSIDE / RSIDE / INT；桌面缩略图轨 + 移动端 swipe |
| Buy Box | 标题、阶梯价、MOQ、廓形摘要、材质徽章 |
| Size Grid | 尺码选择；售罄尺码仍显示 Sold Out |
| Size Guide | 内联展开完整尺码映射表 |
| Quick Quote | 预填廓形、材质、Logo 位置、SKU |
| Accordion ×5 | Description / Specification / Materials / Customization / Shipping |
| Cross-sell | 同分类最多 4 个推荐 SKU |
| 移动端 sticky CTA | 底部固定 Quick Quote 条 |
| JSON-LD | Product + BreadcrumbList |

#### 当前限制

- 无分面筛选（材质、价格档等）
- 数据为 mock，非 live API
- 无购物车 / 在线支付

### 3.3 CASES — 案例 `/cases`

**页面文件：** [`src/pages/CasesPage.tsx`](../src/pages/CasesPage.tsx)  
**数据来源：** [`src/data/cases.ts`](../src/data/cases.ts)

**业务目标：** 通过真实订单故事建立社会证明，参考竞品 Fuanger 的案例模块。

#### 每条案例包含

| 字段 | 说明 |
|------|------|
| 国家 + 数量 | 如 Iceland · 200 pcs |
| 标题 | 项目简述 |
| 摘要 | 工艺与市场背景 |
| 亮点列表 | 如打样确认、3D puff、多色等 |
| 日期 | 项目时间 |
| 配图 | 演示用产品图（上线前替换为真实案例摄影） |

#### 当前案例（3 条）

1. 冰岛零售商 200 顶 Mesh Trucker
2. 瑞典品牌 1,000 顶 Faux Suede Trucker（3 色）
3. 美国体育项目 500 顶 Structured Snapback

#### 转化路径

页面底部 **Start your program →** 链接至 `/contact`。

#### 当前限制

- 无独立案例详情页（`/cases/:slug` 未实现）
- 数据为静态模板，需上线前核实

### 3.5 ABOUT — 关于我们 `/about`

**页面文件：** [`src/pages/AboutPage.tsx`](../src/pages/AboutPage.tsx)  
**配置来源：** [`src/config/merchant.ts`](../src/config/merchant.ts)

**业务目标：** 展示工厂实力与交易透明度，降低 B2B 买家对海外供应商的不信任感。

#### 页面内容

| 区块 | 内容 |
|------|------|
| 公司简介 | 法人名称、注册年份、地址 |
| 工厂图片 | 车间 + 产线（演示图，上线前替换） |
| Capabilities | QC 团队、R&D、外贸团队、语言支持 |
| Main markets | 主要出口市场分布条形图 |
| Lead times | 打样 / 500 / 1,000 / 5,000 件大货交期 |
| Trade terms | Incoterms、付款方式、T/T 结构 |
| Material Strip | 5 种材质教育条（与首页复用） |

#### 与 Contact 的分工

- **About** = 「我们是谁、能力如何、交易条件是什么」
- **Contact** = 「如何联系、如何发起询盘」

### 3.6 CONTACT — 联系我们 `/contact`

**页面文件：** [`src/pages/ContactPage.tsx`](../src/pages/ContactPage.tsx)  
**表单组件：** [`src/components/inquiry/ContactInquiryForm.tsx`](../src/components/inquiry/ContactInquiryForm.tsx)

**业务目标：** 全站 B2B 询盘转化中枢，整合表单、Quick Quote 与多渠道联系。

#### 页面布局（双栏）

**左栏 — ContactInquiryForm 完整询盘表单**

| 字段 | 说明 |
|------|------|
| 姓名 / 邮箱 | 必填 |
| 国家码 + 电话 | 可选 |
| 产品类型 | 下拉选择 |
| 数量档 | 如 50–499 / 500–999 等 |
| 留言 | 帽型、Logo 工艺、目标交期等 |
| 首选渠道 | WhatsApp / Email / 即时通讯 |

**右栏 — 三个卡片**

| 卡片 | 功能 |
|------|------|
| Quick Quote | 打开结构化 brief 弹窗（帽型 / 数量 / Logo 位置 / 材质） |
| Direct channels | WhatsApp、邮箱、Alitalk 直链 |
| E-Catalog | 下载 PDF 产品目录 |

#### 与全站 Quick Quote 的关系

Contact 页的 Quick Quote 与 Header / Hero / Footer / FAB / PDP 触发的是同一个弹窗（`useQuoteStore`），只是 `location` 埋点参数不同。

## 五、全站共享功能（与导航配合）

| 功能 | 组件 | 说明 |
|------|------|------|
| Quick Quote Modal | `QuickQuoteModal` | 全站懒加载；必填 4 字段：帽型 / 数量 / Logo 位置 / 材质 |
| Floating Contact FAB | `FloatingContact` | 右下角 WhatsApp + Quick Quote；PDP 页自动上移 |
| Search Modal | `SearchModal` | 搜索产品、廓形、Blog 文章 |
| i18n | `LocaleProvider` | EN / ES / DE / FR |
| Announcement Bar | `AnnouncementBar` | 顶部促销轮播 |

### Quick Quote 提交行为

1. 组装 plain-text brief  
2. 打开 WhatsApp / Email / Alitalk deep link  
3. 自动复制剪贴板  
4. **无服务端存储**（上线后可接 CRM / 邮件 API）

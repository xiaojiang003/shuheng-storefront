### 3.7 Quick Quote 询盘弹窗（全站）

**必填 4 字段：**

| 字段 | 控件 |
|------|------|
| Cap Style | 8 廓形 +「Not sure yet」 |
| Quantity | 数字 + 预设 50/100/300/500/1000/5000+ |
| Logo Placement | 多选，最多 4 处 |
| Material | 5 材质 +「Recommend for me」 |

**可选字段：** 装饰工艺、稿件状态、Pantone、目标交期、目的国/港口、Buyer Reference、首选渠道

**条件逻辑（已补全 v2.0 空白项）：**
- Fleece 材质 → 禁用 Sublimation 工艺
- Logo 满 4 处 → 其余 chip 禁用
- Artwork = Ready → 显示 Pantone 输入框
- 目标交期最早 = 今天 + 7 天

**提交行为：** 组装 plain-text brief → 打开 WhatsApp/Email/Alitalk deep link → 自动复制剪贴板 → 确认态可再次复制。**无服务端存储。**

### 🟡 强烈建议（影响转化与 SEO）

| 缺项 | 现状 | 举例 |
|------|------|------|
| **SSR / 预渲染** | 纯 SPA，JSON-LD 客户端注入 | Google 可爬但不稳定；建议 Vite SSR 或 prerender 首页 + 全部 PDP |
| **Search 功能** | Header 搜索按钮无逻辑 | 需搜索 UI + 产品索引（Phase 2 或 Algolia） |
| **Legal 页面** | Footer 无 Terms / Privacy 链接 | 需 `/terms`、`/privacy` 页面及内容 |
| **favicon / OG 图** | 仅简单 SVG favicon | 需 1200×630 社交分享图、完整 meta og:title/description |
| **真实 Logo** | Header 仅文字「Shuheng」 | 替换为品牌 wordmark SVG |
| **Silhouette 线稿** | 8 个廓形共用同一占位 SVG | 需 8 张独立 line-art 图标 |
| **尺码库存同步** | mock 中 `7¾` 标 Sold Out | 需确认库存维护方（商户 ops）及更新频率（文档默认 weekly） |
| **Analytics 接入** | 仅 dev console | 接 GA4 / 自建：`silhouette_click`、`quick_quote_submit` 等事件 |
| **多语言** | 仅英文 | 商业支持 12 语言，Phase 1 默认 EN；若目标市场含西/日/德需 i18n |

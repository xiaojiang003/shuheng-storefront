## 二、全局功能（每个页面共享）

| 功能 | 说明 |
|------|------|
| **Announcement Bar** | 顶部 3 条轮播（MOQ / 打样 / 季节款），可关闭，session 记忆 |
| **Header** | 粘性深色导航；首页透明覆盖 Hero；含 **Search 弹窗**、Quick Quote、**Language Switcher** |
| **Footer** | 五列（Shop / Use Cases / Company / Silhouettes / Contact）+ E-Catalog + Privacy/Terms |
| **Quick Quote Modal** | 全站懒加载弹窗，可从 Header / Hero / Footer / FAB / PDP / Contact 触发 |
| **Floating Contact FAB** | 右下角 WhatsApp + Quick Quote；PDP 页自动上移避开 sticky CTA |
| **i18n** | EN / ES / DE / FR 客户端切换（`LocaleProvider`） |
| **Search Modal** | 产品 + 廓形 + Blog 索引搜索 |
| **设计 Token 系统** | ink / brand / accent 等，Tailwind 4 `@theme` 统一管理 |
| **Analytics 事件** | 开发模式 console 输出；生产需接 GA/自建埋点 |

## 三、各页面功能详情

### 3.1 首页 `/`

| # | 区块 | 功能 |
|---|------|------|
| 1 | Announcement Bar | MOQ、打样、季节款轮播 |
| 2 | Header | 透明变体 + 主导航 + Search + 语言切换 |
| 3 | Hero | 全屏品牌图 + **MOQ/Factory/Response 三 badge** + Quick Quote CTA |
| 4 | Category Grid | 4 格入口：6-Panel / Trucker / Bucket / Dad Hats |
| 5 | **Factory Stats** | 注册年 / 产能 / 市场数 / 响应时间数字条 |
| 6 | New Arrivals | API 驱动 8 张产品卡；失败静默 + 静态兜底 |
| 7 | Silhouette Slider | 8 种廓形横向滑轨，链接至 `/silhouette/:key` |
| 8 | Capability Icons | 4 张能力卡片 |
| 9 | **Production Process** | 5 步生产流程（需求 → 设计 → 打样 → QC → 发货） |
| 10 | Material Strip | 5 种材质图标 + 一句话描述 |
| 11 | **Certification Badges** | BSCI / ISO 等认证行（需替换为真实认证） |
| 12 | **Testimonials** | 3–6 条客户评价（需上线前核实） |
| 13 | Size Education | 跳转 `/sizing-guide` + `/fit-finder` |
| 14 | **FAQ Preview** | 3 条预览 + 链接 `/faq` |
| 15 | Enquiry Block | Quick Quote + WhatsApp 直链 |
| 16 | Footer | 全站页脚 + E-Catalog + Legal |

**SEO：** 首页输出 Organization JSON-LD。

---

### 3.2 商品列表 `/collection`

| 功能 | 说明 |
|------|------|
| 商品网格 | 3 列 ProductCard（图 / 标题 / 价格区间 / MOQ / 材质图标） |
| 分类过滤 | URL 参数 `:category` 或 `?silhouette=` |
| 排序 | `?sort=newest` 支持（mock 数据倒序） |
| 结果计数 | 显示 `{n} results` |

**当前限制：** 无分面筛选；数据为 4 个 mock SKU，非 live API。

---

### 3.3 商品详情 `/product/:slug`

| 功能 | 说明 |
|------|------|
| 面包屑 | Home → 分类 → 商品名 |
| 6 角度 Gallery | 3QL / F / R / LSIDE / RSIDE / INT；桌面缩略图轨 + 移动 swipe |
| Buy Box | 标题、阶梯价、MOQ、廓形摘要、材质徽章 |
| Size Grid | 尺码 radiogroup；售罄尺码仍显示（Sold Out） |
| Size Guide | 内联展开完整尺码映射表 |
| Quick Quote | 预填廓形、材质、Logo 位置、SKU |
| Accordion ×5 | Description / Specification / Materials / Customization / Shipping |
| Cross-sell | 同分类 4 个推荐 SKU |
| 移动端 sticky CTA | 底部固定 Quick Quote 条 |
| JSON-LD | Product + BreadcrumbList `@graph` |

---

### 3.4 关于我们 `/about`

- 公司注册信息、QC/R&D/外贸团队规模
- 主要市场分布条形图
- **交期透明化**（打样 / 大货天数，来自 `merchant.leadTimes`）
- **付款条款**（T/T 比例，来自 `merchant.paymentTerms`）
- 材质教育条（Material Strip 复用）

---

### 3.5 联系我们 `/contact`

- Quick Quote 入口（结构化 brief）
- **ContactInquiryForm** — 国家码 + 产品类型 + 数量档 + 渠道 hand-off
- WhatsApp / Email / Alitalk 直链
- 工厂地址

---

### 3.6 FAQ `/faq`

- 8 条手风琴（MOQ / 交期 / 认证 / 面料 / 响应 / 售后 / 尺码 / 目录）
- FAQPage JSON-LD

---

### 3.7 Blog / Cases / Use Cases

- **Blog** — 3 篇：GSM 指南、棉 vs 涤、尺码选择；与 Sizing Guide 互链
- **Cases** — 2–3 个真实订单故事模板（国家 + 数量 + 工艺）
- **Use Cases** — Sports / Streetwear / Corporate 场景 landing

---

### 3.8 Quick Quote 询盘弹窗（全站）

**必填 4 字段：** Cap Style / Quantity / Logo Placement / Material

**可选字段：** 装饰工艺、稿件状态、Pantone、目标交期、目的国/港口、Buyer Reference、首选渠道

**提交行为：** 组装 plain-text brief → 打开 WhatsApp/Email/Alitalk deep link → 自动复制剪贴板。**无服务端存储。**

## 六、上线前缺少的内容（举例）

### 🔴 阻塞上线（必须补齐）

| 缺项 | 现状 | 行动 |
|------|------|------|
| **真实产品数据** | 仅 4 个 mock SKU | 导入 Top 20 catalogue |
| **6 角度产品摄影** | 占位 SVG 图 | 每 SKU 6 张 webp；跑 `verify:angles` 全绿 |
| **Hero / 分类图** | 占位图 | 4 张品类图 + 1 张 Hero 生活方式图 |
| **New Arrivals live API** | 未配置 `VITE_PRODUCT_API_URL` | 配置生产 API |
| **渠道联系方式** | WhatsApp 占位号 | 换真实 WhatsApp Business 号码 |
| **域名 & 部署** | `merchant.siteUrl` 为示例 | 绑定真实域名 + HTTPS |
| **评价 / 认证内容** | placeholder 数据 | 替换为可核实真实内容 |

### 🟡 强烈建议

| 缺项 | 说明 |
|------|------|
| **SSR / 预渲染** | 纯 SPA；建议 prerender 首页 + PDP |
| **E-Catalog PDF** | 当前占位 PDF，需完整产品目录 |
| **favicon / OG 图** | 需 1200×630 社交分享图 |
| **真实 Logo** | Header 文字 → wordmark SVG |
| **Analytics 接入** | 接 GA4 |
| **Silhouette 线稿** | 8 张独立 line-art 图标 |
